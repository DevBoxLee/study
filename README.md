# 우리집 금융공부 & 투자설계

부부가 같은 교육용 사례로 금융 개념을 배우고 투자 운영규칙까지 만드는 정적 사이트입니다.

**사이트:** https://devboxlee.github.io/study/

## 학습 구성

00 투자원칙 → 01 투자 가능한 돈 → 02 기간·목표 → 03 위험·수익 → 04 자산배분 → 05 ETF → 06 계좌·세금 → 07 운영규칙. 06에는 ISA·연금저축·IRP·일반계좌 상세 페이지가 있으며 99는 필요한 시점에 공부할 주제를 보관합니다.

공통 사례: 금융자산1억원, 비상금1500만원, 목적자금2500만원, 장기자금6000만원, 월150만원 추가 적립. 실제 가구 평균이나 개인 재무자료가 아닙니다.

## 내용 추가 방법

1. `content/_template.md`를 복사해 고유 `id`, 제목, 분류, 확인일을 작성합니다.
2. 기존 챕터 하위에 넣으려면 `parent`에 그 챕터의 `id`를 적습니다. 파일명·id는 영어 소문자/숫자/하이픈을 권장합니다.
3. 새 주제는 먼저 필수/필요할 때/후순위를 판단합니다. 필수만 공식자료 조사→검증→개념·숫자·시각자료→전략·체크리스트 순서로 작성합니다.
4. 세법은 공식자료를 확인하고 현행법과 정부안을 분리합니다. 링크·확인일을 본문에 기록합니다.
5. 변경을 PR로 올립니다. 검사 후 `main`에 병합하면 GitHub Actions가 사이트를 자동 배포합니다.

필요하면 `published: false`로 초안을 숨깁니다. 순서는 파일명 정렬이며 하위 자료는 `parent` 아래에 표시됩니다. 빌더는 동일한10개 학습 섹션과 출처가 없는 문서에 오류를 냅니다. 새 문서는 일단99 아래에서 검토하고 필수로 선별한 후 위치를 이동합니다.

지원 문법: 제목·문단·굵게·인라인 코드·목록·링크·표·코드블록. 임의 HTML과 전체 Markdown 문법은 지원하지 않습니다. 계산 위젯은 `:::compound` 등 사전 등록 이름을 사용합니다.

## 로컬 실행과 검증

필요 런타임은 Python3.12+ 및 테스트용 Node22+입니다. 사이트 자체에는 Node·npm·서버·DB가 필요하지 않습니다.

```bash
python tools/build_site.py
python -m http.server 8000 --directory dist
node tests/math.test.cjs
python -m unittest discover -s tests -p 'test_*.py'
```

화면 검증은 별도 개발 의존성 `playwright@1.56.1`을 사용합니다. `npm install --no-save playwright@1.56.1 && npx playwright install --with-deps chromium` 후 `node tests/browser.cjs`로 실행합니다. 개발 의존성은 배포 사이트에 포함되지 않습니다. CI는 화면 검사 결과를 artifacts로 보관합니다.

## 저장소 구성

- `content`: 편집할 원본 Markdown
- `tools`: Python 표준 라이브러리 빌더, 기존 ZIP의 렌더러를 개선해 재사용
- `src/shell.html`: 본문·트리 공통 레이아웃
- `assets`: CSS, 브라우저 계산과 상호작용
- `tests`: 계산·빌드·화면 검증
- `docs`: 합의 설계·실행계획·Fact Check
- `.github/workflows/pages.yml`: 검사와 자동 배포

`dist`는 재생성 가능한 출력이며 Git에 커밋하지 않습니다. Pages에는 `dist`만 올라갑니다. 비밀키나 실제 소득·잔액·계좌번호를 저장소에 기록하지 않습니다.

## 운영 특성

본문은 빌드 시 포함되고 CDN을 사용하지 않습니다. /study/ 상대경로와 hash 링크로 작동합니다. 검색은 제목·본문을 대상으로 합니다. 학습체크는 해당 기기의 localStorage에 저장되며 부부 간 동기화되지 않습니다. 계산 입력값은 저장·전송하지 않습니다. 실제 세법·조건은 거래 시점에 재확인합니다.

확인일2026-09-30. 원문 접근이 안 된 영상은 확인했다고 단정하지 않았습니다. 제한은 `docs/fact-check.md`에 기록했습니다.
