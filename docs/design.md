# 우리집 금융공부 v1 — 합의한 설계

2026-09-30. 사용자의 기존 합의(전체 과정 적용, Git 권한 위임, GitHub Pages 게시)를 실행한다.

## 목적과 범위
부부가 동일한 교육용 사례로 필수 금융지식을 이해하고 투자 운영규칙까지 만드는 정적 학습 사이트. 금융 백과사전으로 확장하지 않는다. 실제 개인 재무정보를 수집하지 않는다.

## 공통 사례
금융자산 1억원 = 비상금 1,500만원 + 3년 내 목적자금 2,500만원 + 장기자금 6,000만원. 월 추가 투자 150만원. 기간 20~30년. 통계상 평균이 아닌 임의의 교육용 사례다.

## 화면과 콘텐츠
좌측 트리 00~07 및 99, 우측 학습본문. 검색, 모바일 메뉴, 챕터 이동, 기기별 학습 체크. 모든 챕터에 왜 알아야 하는가/개념/원리/숫자/시각자료/주의사항/전략 영향/교육용 부부 전략/실행 체크/공식 출처를 넣는다. 절세계좌 비교 허브와 ISA·연금저축·IRP·일반계좌 상세 페이지를 제공한다.

## 구조
content/*.md → Python 표준 라이브러리 빌더 → dist/index.html 및 assets. 기존 ZIP의 경량 Markdown 렌더러를 재사용하되 기존 세제 안내문은 검증 없이 승계하지 않는다. HTML/CSS/JS 외의 제품 런타임, DB, CDN 의존성은 없다. 상대경로 및 hash 라우팅으로 /study/에서 동작한다. 내용은 빌드 시 포함되어 읽기 요청 실패를 피한다.

## 계산
월말 납입, 연 유효수익률 r의 월 환산 (1+r)^(1/12)-1. 0%·음수 수익률 및 물가 반영. 수익률은 예측이 아니다. 하락률의 원금 회복률, 주식/안정자산 동반 하락 스트레스, ISA 세금, 소득별 연금 세액공제 예제. 계산 입력은 저장하지 않는다.

## 검증과 게시
계산 단위검증, 콘텐츠 메타데이터/출처/내부 링크 검증, 데스크톱·모바일 화면 및 키보드 동작 확인. feature 브랜치 → PR → 검증 → main 병합 → Actions 배포. 실제 배포 상태와 공개 페이지를 확인한다. 공식 문서로 확인된 현행 안내와 정부안을 명시적으로 분리한다.
